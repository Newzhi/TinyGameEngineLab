## 1. 为什么需要摄像机系统？

Day 06 的立方体场景里，相机被**写死**在 `(0, 0, 3)` 看向原点：

```cpp
glm::mat4 view = glm::lookAt(
    glm::vec3(0.0f, 0.0f, 3.0f),
    glm::vec3(0.0f, 0.0f, 0.0f),
    glm::vec3(0.0f, 1.0f, 0.0f)
);
```

这能展示 3D 效果，但无法：

1. **在场景中自由移动**（走近/走远物体）
2. **环视四周**（转头看不同方向）
3. **像游戏一样**用 WASD + 鼠标控制视角

**摄像机系统**就是把「相机状态」（位置、朝向）从硬编码变成**可更新、可交互**的逻辑，每帧算出 View 矩阵传给 Shader。

---

## 2. OpenGL 里没有「Camera 对象」

OpenGL 是图形 API，**不内置 Camera 类**。所谓「相机」在数学上就是 **View 矩阵**：

```
p_eye = M_view * p_world
```

| 概念 | 实际是什么 |
|------|-----------|
| 相机 | 一个观察参考系（原点 + 三个轴） |
| 相机移动 | 更新 View 矩阵 |
| 相机类（Camera） | **C++ 自己封装的工具类**，用来方便算 View 矩阵 |

LearnOpenGL 教程里的 `Camera` 类不是 OpenGL 标准，而是把 `lookAt` 需要的参数（位置、前向、上向等）组织起来。

---

## 3. 相机的三个核心向量

一个相机在世界空间里由 **三个互相垂直的向量** 定义：

```
        up（上）
         ↑
         |
    eye ●----→ front（前/观察方向）
        /
       ↙ right（右）
```

| 向量 | 符号 | 含义 |
|------|------|------|
| **Position** | 相机位置 | 相机在世界坐标中的点 `eye` |
| **Front** | 前向 | 相机看向的方向（单位向量） |
| **Up** | 上向 | 相机头顶指向的方向（单位向量） |

**Right** 通常不由用户直接设置，而是由叉积算出：

```
right = normalize(cross(front, worldUp))
up    = normalize(cross(right, front))
```

`worldUp` 一般是 `(0, 1, 0)`，表示「世界的上方向是 Y 轴正方向」。

### 3.1 `lookAt` 的三个参数

GLM 的 `glm::lookAt(eye, center, up)` 正好对应：

| 参数 | 含义 |
|------|------|
| `eye` | 相机位置 Position |
| `center` | 观察目标点 = `eye + front` |
| `up` | 相机的 Up 向量 |

```cpp
glm::mat4 view = glm::lookAt(eye, eye + front, up);
// 等价于
glm::mat4 view = glm::lookAt(position, position + front, up);
```

Day 06 里 `center = (0,0,0)` 是因为相机正对着原点，此时 `front ≈ (0, 0, -1)`。

## 4. View 矩阵 = 相机变换的「逆」

若把相机本身看成场景里的一个物体，它有自己的 **平移 + 旋转**（Model 矩阵）。但 View 矩阵要做的是**相反**的事：

> **把整个世界变到以相机为原点的坐标系**，而不是把相机变到世界里。

```
M_view = inverse(M_camera)
```

| 操作 | 相机变换 (M_camera) | View 矩阵 (M_view) |
|------|---------------------|-------------------|
| 相机向右移 | 相机 +X 平移 | 整个世界 -X 平移 |
| 相机向左转 | 相机绕 Y 左转 | 整个世界绕 Y 右转 |

**直觉**：你向右走一步，等价于世界向左移一步——View 矩阵实现的就是这种「相对运动」。

`glm::lookAt` 内部已经帮你算好了这个逆变换，无需手算 `inverse`。

## 5. 两种常见相机控制方式

### 5.1 观察目标式（Look-At / Orbit）

相机始终**看向某个固定点**（如场景中心、某个物体）：

```
eye 可以变（绕目标旋转、拉近拉远）
center 固定或跟随目标
```

| 优点 | 缺点 |
|------|------|
| 实现简单 | 无法「自由环视」到任意方向 |
| 适合展示模型、轨道摄影 | 不适合第一人称游戏 |

Day 06 当前就是这种：`center = (0,0,0)` 固定。

### 5.2 第一人称 / FPS 式（Free Look）

相机**不绑定固定目标点**，由 `front` 向量决定看哪里：

```
view = lookAt(position, position + front, up)
```

| 输入 | 效果 |
|------|------|
| W / S | 沿 front 前进 / 后退 |
| A / D | 沿 right 左移 / 右移（平移，不转向） |
| 鼠标移动 | 改变 front（环视） |

| 优点 | 缺点 |
|------|------|
| 自由度高，像 3D 游戏 | 需要维护 front/up，处理万向锁等 |

LearnOpenGL Day 07 及之后主要实现这种。

## 6. 欧拉角：Yaw 与 Pitch

FPS 相机通常用 **Yaw（偏航）** 和 **Pitch（俯仰）** 两个角度描述朝向：

```
         Y
         ↑
         |   yaw：绕 Y 轴水平转动（左右看）
         |
         O ───→ X
        /
       ↙ Z

pitch：绕 right 轴垂直转动（抬头/低头）
```

| 角 | 绕谁转 | 效果 |
|----|--------|------|
| **Yaw** | 世界 Y 轴 | 左右转头 |
| **Pitch** | 相机 right 轴 | 抬头 / 低头 |
| Roll | 相机 front 轴 | 倾斜（FPS 一般锁定为 0） |

鼠标移动时更新角度，再算出 `front`：

```cpp
front.x = cos(yaw) * cos(pitch);
front.y = sin(pitch);
front.z = sin(yaw) * cos(pitch);
front = normalize(front);
```

### 6.1 万向锁（Gimbal Lock）

当 **pitch = ±90°**（正上/正下）时，front 与 worldUp 平行，叉积 `cross(front, worldUp)` 趋近于零，`right` 方向不稳定，左右转和上下转「耦合」。

常见处理：

| 方法 | 说明 |
|------|------|
| **限制 pitch** | 如 `pitch ∈ [-89°, 89°]`，不让头完全抬到顶 |
| **四元数** | 用 `glm::quat` 代替欧拉角，高级场景常用 |

入门阶段限制 pitch 范围即可。

## 7. 键盘移动：沿 front / right 平移

WASD 不改变朝向，只改变 **Position**：

```
前进：position += front * speed
后退：position -= front * speed
右移：position += right * speed
左移：position -= right * speed
```

其中：

```
right = normalize(cross(front, worldUp))
```

注意：**只改 position，不改 front**，所以「平移」和「环视」是分开的。

## 8. deltaTime：帧率无关的平滑移动

若每帧移动固定距离：

```cpp
position += front * 0.05f;   // 每帧走 0.05
```

60 FPS 时每秒走 3 单位，144 FPS 时每秒走 7.2 单位——**速度随帧率变化**。

正确做法：用 **deltaTime**（上一帧到这一帧的时间差，单位秒）：

```cpp
float currentFrame = glfwGetTime();
deltaTime = currentFrame - lastFrame;
lastFrame = currentFrame;

float cameraSpeed = 2.5f * deltaTime;   // 每秒 2.5 单位
position += front * cameraSpeed;
```

| 变量 | 含义 |
|------|------|
| `deltaTime` | 本帧耗时（秒） |
| `cameraSpeed = 2.5f * deltaTime` | 本帧应移动的距离 |

这样无论 60 还是 144 FPS，**每秒移动距离恒定**。

## 9. 鼠标输入：改变朝向

GLFW 可捕获鼠标并隐藏光标（FPS 模式）：

```cpp
glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_DISABLED);
glfwSetCursorPosCallback(window, mouse_callback);
```

回调里根据鼠标位移更新 yaw / pitch：

```
xoffset = 当前鼠标 x - 上次鼠标 x
yoffset = 上次鼠标 y - 当前鼠标 y   // 注意 Y 轴通常要反

yaw   += xoffset * sensitivity
pitch += yoffset * sensitivity
```

`sensitivity` 控制鼠标灵敏度（如 0.1）。

## 10. Camera 类：常见封装结构

LearnOpenGL 风格会把相机状态和方法封装成类：

```
Camera
├── 成员变量
│   ├── position, front, up, right, worldUp
│   ├── yaw, pitch
│   ├── movementSpeed, mouseSensitivity, fov
│   └── （可选）zoom
├── 方法
│   ├── GetViewMatrix()     → 返回 lookAt 矩阵
│   ├── ProcessKeyboard()   → WASD 改 position
│   ├── ProcessMouseMovement() → 改 yaw/pitch，更新 front
│   └── updateCameraVectors()  → 由 yaw/pitch 重算 front/right/up
```

每帧渲染循环：

```cpp
// 1. 处理输入
camera.ProcessKeyboard(FORWARD, deltaTime);
// 鼠标在 callback 里 ProcessMouseMovement

// 2. 取 View 矩阵
glm::mat4 view = camera.GetViewMatrix();

// 3. 传给 Shader
ourShader.setMat4("view", view);
```

**View 必须在循环内更新**——相机一动，View 就变。

## 11. View 与 Projection 的分工

| 矩阵 | 管什么 | 典型参数 |
|------|--------|----------|
| **View** | 相机在哪、朝哪看 | position, front, up |
| **Projection** | 视野多宽、近远裁剪、透视/正交 | FOV, aspect, near, far |

相机类有时也存 **FOV**（鼠标滚轮缩放 = 改 FOV，不是改 position）：

```cpp
projection = glm::perspective(glm::radians(camera.Zoom), aspect, 0.1f, 100.0f);
```

| 操作 | 改 View | 改 Projection |
|------|---------|---------------|
| WASD 移动 | ✅ | — |
| 鼠标环视 | ✅ | — |
| 滚轮 zoom | — | ✅（改 FOV） |

## 12. 与 Day 06 MVP 的关系

```
局部坐标 (aPos)
    → model       物体怎么摆
    → view        相机怎么看  ← Day 07 重点
    → projection  镜头参数（FOV 等）
    → gl_Position
```

Day 06 已实现 model + 固定 view + projection。Day 07 要做的是：

1. 把 `view` 从循环外硬编码 → **循环内由 Camera 动态计算**
2. 加入键盘 / 鼠标 / deltaTime
3. （可选）封装 `Camera` 类

Shader **不需要改**——仍然接收 `uniform mat4 view`。

## 13. 完整数据流（Day 07 目标）

```
输入（键盘/鼠标）
    ↓
更新 Camera 状态（position, yaw, pitch, front...）
    ↓
camera.GetViewMatrix()  →  glm::lookAt(...)
    ↓
ourShader.setMat4("view", view)
    ↓
projection * view * model * vec4(aPos, 1.0)
    ↓
屏幕上的 3D 场景（可自由漫游）
```

## 14. 概念对比表

| 概念 | 说明 |
|------|------|
| Eye / Position | 相机在世界中的位置 |
| Center / Target | 观察目标点；FPS 模式下 = position + front |
| Front | 单位向量，相机朝向 |
| Up | 单位向量，相机头顶方向 |
| View 矩阵 | 世界 → 观察空间 |
| Yaw | 水平转角 |
| Pitch | 垂直转角 |
| deltaTime | 帧间隔，保证移动速度不随 FPS 变化 |
| Camera 类 | C++ 封装，不是 OpenGL 内置 |
