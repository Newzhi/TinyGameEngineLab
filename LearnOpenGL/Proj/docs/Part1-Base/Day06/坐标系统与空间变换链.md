## 1. 为什么需要多种坐标系？

Day 04~05 的矩形顶点直接写在 **NDC**（归一化设备坐标）附近：

```cpp
0.5f, -0.5f, 0.0f   // 范围约 [-1, 1]
```

这在教学上可行，但无法表达：

1. 多个物体各自有局部原点（模型坐标）
2. 相机可以移动、旋转（观察坐标）
3. 近大远小的 3D 透视（投影）

因此 OpenGL 管线把变换拆成多个**空间（Space）**，每个空间配一个**变换矩阵**。

## 2. 五种坐标空间（由局部到屏幕）

```
局部空间 (Local / Model Space)
    ↓  Model 矩阵
世界空间 (World Space)
    ↓  View 矩阵
观察空间 (View / Eye / Camera Space)
    ↓  Projection 矩阵
裁剪空间 (Clip Space)
    ↓  透视除法 (÷ w)
NDC（归一化设备坐标）
    ↓  视口变换 (Viewport)
屏幕空间 (Screen Space)
```

### 2.1 局部空间（Local / Model Space）

- 以**模型自身原点**为参考的坐标
- 建模软件（Blender 等）导出的顶点通常在此空间
- 例如：一个立方体中心在 `(0,0,0)`，八个角在 `±1`

**Model 矩阵** 负责：平移、旋转、缩放 → 把物体放到世界中的某个位置。

### 2.2 世界空间（World Space）

- 整个场景的**统一坐标系**
- 所有物体、光源、相机位置都在此表达
- 例：桌子在 `(0,0,0)`，杯子在 `(1, 0.5, 0)`

```
p_world = M_model * p_local
```

### 2.3 观察空间（View / Eye Space）

- 以**相机为原点**的坐标系
- 相机默认看向 **-Z**（OpenGL 右手系约定）
- **View 矩阵** = 把世界变到「相机眼里」

```
p_eye = M_view * p_world
```

`glm::lookAt(eye, center, up)` 构造的正是这个矩阵（本质是相机变换的**逆**）。

### 2.4 裁剪空间（Clip Space）

- 顶点着色器输出的 `gl_Position` 就在此空间
- 是**齐次坐标** `(x_c, y_c, z_c, w_c)`
- GPU 做**视锥裁剪**：若某分量超出 `[-w, w]`，顶点被丢弃

```
p_clip = M_projection * p_eye
```

### 2.5 NDC（Normalized Device Coordinates）

- 透视除法后得到，范围通常 **x, y, z ∈ [-1, 1]**
- 是一个**单位立方体**，与窗口分辨率无关

```
x_ndc = x_c / w_c
y_ndc = y_c / w_c
z_ndc = z_c / w_c
```

### 2.6 屏幕空间（Screen Space）

- 由 `glViewport(x, y, width, height)` 把 NDC 映射到像素
- 例如 NDC `(-1, -1)` → 窗口左下角像素 `(0, 0)`

```
x_screen = (x_ndc + 1) / 2 * W + x_offset
```

（y 轴可能翻转，取决于 API 约定）

## 3. 右手坐标系约定

OpenGL 使用**右手坐标系**：

```
        y
        ↑
        |
        O ──────→ x
       /
      ↙ z（指向屏幕外）
```

| 规则 | 说明 |
|------|------|
| 拇指 x，食指 y，中指 z | 右手定则 |
| 相机默认看向 -Z | `lookAt` 时物体通常在 z 负方向 |
| 叉积方向 | `right = cross(forward, up)` |

**注意**：观察空间是右手系，但 NDC 的 z 方向与观察空间相反（Song Ho 文中称为 eye space 右 handed、NDC 左 handed 的 z 轴差异）。投影矩阵负责这一转换。

## 4. MVP 矩阵链（数学形式）

对顶点 `p = (x, y, z, 1)`（列向量）：

```
p_clip = P * V * M * p_local
```

| 矩阵 | 符号 | 作用 |
|------|------|------|
| Model | `M` | 局部 → 世界 |
| View | `V` | 世界 → 观察 |
| Projection | `P` | 观察 → 裁剪 |

GLSL 中（**从右向左**作用于顶点）：

```glsl
gl_Position = projection * view * model * vec4(aPos, 1.0);
```

**顺序不可随意交换**：矩阵乘法不满足交换律。

## 5. 视锥体（Frustum）

透视投影时，观察空间内可见区域是一个**截头四棱锥**：

```
              far plane（远裁剪面）
             /          \
            /            \
           /   可见区域    \
          /________________\
         near plane（近裁剪面）
              ↑
            相机
```

由 6 个参数界定（Song Ho 记法）：

| 参数 | 含义 |
|------|------|
| l, r | 近裁剪面左右边界 |
| b, t | 近裁剪面下上边界 |
| n, f | 近、远裁剪面距离（**取正值**，内部计算时会配合 z 方向约定） |

投影矩阵 + 裁剪阶段共同完成：**视锥裁剪** + **映射到 NDC 立方体**。

详见《投影矩阵数学原理》及参考文献 [Song Ho - OpenGL Projection Matrix](https://www.songho.ca/opengl/gl_projectionmatrix.html)。

## 6. 各空间对比表

| 空间 | 谁定义 | 典型范围 | 由谁变换 |
|------|--------|----------|----------|
| 局部 | 模型 | 任意 | — |
| 世界 | 场景 | 任意 | Model |
| 观察 | 相机 | 任意 | View |
| 裁剪 | GPU 管线 | 齐次，待 ÷w | Projection |
| NDC | 规范 | [-1, 1]³ | 透视除法 |
| 屏幕 | 窗口 | [0, W] × [0, H] | Viewport |

## 8. 裁剪测试（Clip Test）

裁剪空间点 `(x_c, y_c, z_c, w_c)` 必须同时满足：

```
-w_c <= x_c <= w_c
-w_c <= y_c <= w_c
-w_c <= z_c <= w_c
```

不满足的顶点/图元被丢弃。投影矩阵的设计保证：视锥内的点经过透视除法后落在 NDC 立方体 `[-1,1]³` 内。
