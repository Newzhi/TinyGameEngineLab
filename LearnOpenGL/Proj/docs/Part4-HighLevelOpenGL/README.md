# Part 4 — Advanced OpenGL

LearnOpenGL「[高级 OpenGL](https://learnopengl-cn.github.io/04%20Advanced%20OpenGL/01%20Depth%20testing/)」阶段学习笔记，按天组织：

| 目录 | 主题 |
|------|------|
| [Day01](./Day01/) | 深度测试：深度缓冲、深度函数、非线性精度、Early-Z / Pre-Z、深度冲突 |
| [Day02](./Day02/) | 模板测试：模板缓冲、Func/Op/Mask、物体轮廓与其它遮罩用法 |
| [Day03](./Day03/) | 混合：alpha、`discard`、混合方程、半透明排序 |
| [Day04](./Day04/) | 面剔除：环绕顺序、正/背面、`glCullFace` / `glFrontFace` |
| [Day05](./Day05/) | 帧缓冲：FBO、颜色纹理 / RBO、离屏渲染与后处理 |
| [Day06](./Day06/) | 立方体贴图：天空盒、方向采样、反射 / 折射 |
| [Day07](./Day07/) | 高级数据：缓冲填充、分批顶点属性、缓冲复制 |
| [Day08](./Day08/) | 高级 GLSL：内建变量、接口块、Uniform 缓冲 |
| [Day09](./Day09/) | 几何着色器：图元输入输出、房子、爆破、法线可视化 |
| [Day10](./Day10/) | 实例化：实例数组、小行星带 |
| [Day11](./Day11/) | 抗锯齿：MSAA、离屏多重采样 FBO、还原 |
