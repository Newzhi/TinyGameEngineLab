## 0. 术语中英对照

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Face culling | **面剔除** | 丢掉背向（或正向）三角形，不进入后续片元处理 |
| Front face / Back face | **正向面 / 背向面** | 按环绕顺序相对观察者的朝向分类 |
| Winding order | **环绕顺序** | 三角形三个顶点是逆时针还是顺时针 |
| Counter-clockwise (CCW) | **逆时针** | 默认的「正向」环绕 |
| Clockwise (CW) | **顺时针** | 另一种环绕；可设为正向 |
| `glCullFace` | **剔谁** | 丢背面 / 正面 / 两面 |
| `glFrontFace` | **谁算正面** | `GL_CCW` 或 `GL_CW` |

## 1. 为什么要面剔除？

闭合物体（立方体）从任意角度最多看见 **3** 个面，另外至少 3 个面背对相机。  
那些背面照样提交、照样光栅化、照样跑片元着色器 → 白费。

面剔除：在**光栅化之后、昂贵片元工作之前**，把「背向」三角形整片丢掉。封闭网格常能省 **50%+** 片元开销。

注意：草、双面布料、未封闭网格不要盲目开剔除，否则一边会「消失」。

---

## 2. 怎么判断面朝向？（核心）

OpenGL **不读法线** 来做默认面剔除，而是看 **屏幕上三个顶点的环绕方向**：

1. 顶点着色器把三角形三个点变到裁剪空间 → 透视除法后到 NDC / 窗口  
2. 从**观察者看屏幕**，这三个点是逆时针还是顺时针？  
3. 默认：`GL_CCW` → 逆时针 = **正向面**；顺时针 = **背向面**

### 2.1 定义顶点时怎么写？

站在**这个面的外侧**朝里看，三个顶点按 **逆时针** 排列（默认约定）：

```
外侧看过去（期望是正面）：

    2
   / \
  /   \
 0 ——— 1     顺序 0 → 1 → 2 为逆时针 → 正向面
```

同一套「从外侧看是 CCW」的数据，立方体**对面**那一侧从相机看会变成顺时针（因为你在看它的「内侧顺序」）→ 被标成背面 → 可被剔除。

### 2.2 右手定则（和法线一致的直觉）

手指沿顶点顺序弯曲，拇指指向朝外法线方向。  
默认剔除背面时：法线大体朝向相机的面留下，背向相机的面丢掉。

### 2.3 为何「片元不显示」？

被剔除的三角形：

- **不会**进入片元着色器（或几乎不产生有效片元写入）  
- **不会**写入颜色 / 深度  

所以不是「画了但透明」，而是 **这个三角形根本没留下来**。  
飞进立方体内部时，原来的内壁相对你变成「背面」→ 全被剔掉 → 看到穿透/空洞，这是预期现象。

## 3. API 怎么开？

```cpp
glEnable(GL_CULL_FACE);   // 默认关；打开后才剔
glCullFace(GL_BACK);      // 默认：剔背面（最常用）
glFrontFace(GL_CCW);      // 默认：逆时针算正面
```

### `glCullFace`

| 参数 | 行为 |
|------|------|
| `GL_BACK` | 只丢背向面（默认） |
| `GL_FRONT` | 只丢正向面（外面没了，像只剩壳内侧） |
| `GL_FRONT_AND_BACK` | 正反都丢 → 什么都不画 |

### `glFrontFace`

| 参数 | 含义 |
|------|------|
| `GL_CCW` | 逆时针 = 正面（默认） |
| `GL_CW` | 顺时针 = 正面 |

实验：`CullFace(BACK)` + `FrontFace(CW)` 时，若顶点仍按 CCW 定义，从外面看会像「只画了背面」——和 `CullFace(FRONT)` + `FrontFace(CCW)` 类似。

## 4. 和深度测试、混合的关系

| | 深度测试 | 面剔除 |
|--|----------|--------|
| 何时 | 片元级，比远近 | 更早：整三角是否留下 |
| 依据 | 深度缓冲 | 环绕顺序 |
| 省什么 | 被挡住的片元 | 整面背向三角 |

草（Day03）通常要 **关掉** 面剔除，否则四边形只剩一侧。  
反射里乘了 `scale(1,1,-1)` 会翻转绕序，需临时改 `CullFace`（镜子 Demo 里做过）。

## 5. 和本工程怎么接

### 5.1 Demo 内容（当前 `main.cpp`）

Demo 只有一个立方体，每个面从外侧看都是 CCW，并在六个面上重复贴
`Resource/Texture/container2.png`。纹理只帮助辨认正反面，不参与朝向判断：

| 模式 | 哪些三角形被丢弃 | 从立方体外看 |
|------|------------------|--------------|
| 关闭剔除 | 都不丢；仍由深度测试决定谁在前面 | 正常外壳 |
| `GL_BACK` | 从相机看呈 CW 的背向面 | 正常外壳；后面的面不做无用片元工作 |
| `GL_FRONT`（Demo 默认） | 从相机看呈 CCW 的正向面 | 近处外壳被拿走，可以看到立方体后方/内部的背面 |

关键不是「正面透明了」：正面三角形在光栅化阶段被丢弃，不产生颜色和深度；因此后面的背向三角形才有机会显示。

按键：

| 键 | 作用 |
|----|------|
| `1` | 关闭面剔除 |
| `2` | 剔背面 `GL_BACK`（默认教学状态） |
| `3` | 剔正面 `GL_FRONT`，直接看到后方背面 |
| WASD + 鼠标 | 从不同角度观察 |

相关文件：

| 文件 | 作用 |
|------|------|
| `src/cppfile/main.cpp` | 单立方体 + 三种剔除模式 |
| `shaders/faceCull.vs` / `faceCull.fs` | 位置 + UV，采样箱子纹理 |
| `Resource/Texture/container2.png` | 六个面共用的观察纹理 |

### 5.2 建议观察顺序

1. 启动默认为 `GL_FRONT`：朝向相机的前、侧、上表面消失，后方背面露出来  
2. 按 `2` 切到常规 `GL_BACK`：看到正常立方体外壳  
3. 按 `1` 关闭剔除：近处外壳由深度测试挡住后方表面  
4. 按 `3` 恢复正面剔除，从不同角度观察  
5. 对比三种模式，理解剔除发生在深度测试前：被剔面不会写深度
