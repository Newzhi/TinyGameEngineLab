# 投影矩阵数学原理（Day 06）

本文档从**数学推导**角度讲解 OpenGL 的 **Projection 矩阵**：如何把观察空间（Eye Space）中的 3D 点映射到裁剪空间，再经透视除法进入 NDC。

主要参考文献：

> **Song Ho Ahn**, [*OpenGL Projection Matrix*](https://www.songho.ca/opengl/gl_projectionmatrix.html), 2008–2024.

配合阅读：《坐标系统与空间变换链》《Day 05 线性代数基础与变换》。

> **公式说明**：本文档公式使用代码块 / 行内代码书写，可在 Markdown 预览中直接阅读（不依赖 LaTeX 渲染）。

## 1. 投影矩阵要解决的问题

显示器是 **2D 平面**，3D 场景必须**投影**成 2D 图像。

**GL_PROJECTION 矩阵**同时完成两件事（[Song Ho Overview](https://www.songho.ca/opengl/gl_projectionmatrix.html)）：

1. **视锥裁剪（Frustum Culling）**：在裁剪空间丢弃视锥外的顶点
2. **NDC 映射**：把视锥内点映射到 `[-1, 1]³` 的标准立方体

完整流程：

```
Eye Space (xe, ye, ze)
    → × Projection Matrix
Clip Space (xc, yc, zc, wc)   ← 齐次坐标
    → 裁剪测试（与 ±wc 比较）
    → 透视除法 (xc/wc, yc/wc, zc/wc)
NDC (xn, yn, zn) ∈ [-1, 1]³
```

---

## 2. 透视除法与 w 分量

裁剪空间点是齐次坐标 `p_c = (x_c, y_c, z_c, w_c)`。

NDC：

```
x_n = x_c / w_c
y_n = y_c / w_c
z_n = z_c / w_c
```

**透视投影**的核心：让 `w_c` 与观察空间的深度 `-z_e` 相关（近大远小的几何来源）。

---

## 3. 透视投影（Perspective Projection）

### 3.1 几何模型

观察空间中的可见区域是**截头四棱锥**（frustum）。透视投影把该 frustum 映射为 NDC 立方体：

| 观察空间 (Eye) | NDC |
|----------------|-----|
| x ∈ [l, r] | x_n ∈ [-1, 1] |
| y ∈ [b, t] | y_n ∈ [-1, 1] |
| z ∈ [-n, -f] | z_n ∈ [-1, 1] |

（z 的范围与 OpenGL 相机看向 -Z 的约定有关；Song Ho 文中 near/far 传参为正，内部配合 eye space 的 -Z 方向处理。）

### 3.2 相似三角形推导 x、y

观察空间一点 `(x_e, y_e, z_e)` 投影到**近裁剪面** `z = -n` 上的点 `(x_p, y_p, -n)`。

**俯视图**（求 `x_p`）：

```
        相机 O
         |\
         | \
         |  \  到 (xe, ye, ze)
         |   \
    -----+----● (xp, -n)  近裁剪面
         |
```

由相似三角形：

```
x_p / x_e = -n / z_e

=>  x_p = n * x_e / (-z_e)
```

同理：

```
y_p = n * y_e / (-z_e)
```

**关键**：`x_p`, `y_p` 与 `-z_e` 成反比 → 远处物体在屏幕上更小（透视效果）。

### 3.3 从投影平面映射到 NDC

将 `[l, r]` 线性映射到 `[-1, 1]`：

```
x_n = (x_p - l) / (r - l) * 2 - 1
```

将 `x_p = n * x_e / (-z_e)` 代入，并整理成「先乘矩阵、再除以 `w_c`」的形式。

[Song Ho 推导](https://www.songho.ca/opengl/gl_projectionmatrix.html)结论：令 `w_c = -z_e`，则投影矩阵第 4 行为 `(0, 0, -1, 0)`。

### 3.4 对称视锥简化

当视锥关于中心轴对称：`l = -r`，`b = -t`，矩阵可简化为：

```
P_sym =
[  n/r,       0,           0,              0  ]
[    0,     n/t,           0,              0  ]
[    0,       0,  -(f+n)/(f-n),           -1  ]
[    0,       0,    -2fn/(f-n),            0  ]
```

（与 Song Ho 透视投影矩阵一致。）

### 3.5 z 方向的非线性映射

与 x、y 不同，`z_n` 必须满足：

- 近裁剪面 `z_e = -n`  =>  `z_n = -1`
- 远裁剪面 `z_e = -f`  =>  `z_n = 1`
- 同时保留深度缓冲所需的单调性，且可**反投影（unproject）**

Song Ho 设：

```
z_c = A * z_e + B * w_c,    w_c = -z_e
```

代入边界条件解出：

```
A = -(f + n) / (f - n)
B = -2 * f * n / (f - n)
```

因此：

```
z_n = z_c / w_c
    = (A * z_e + B * w_c) / (-z_e)
    = A * (z_e / (-z_e)) - B
```

这是 **`z_e` 与 `z_n` 的非线性有理函数**（Song Ho eq.(3)）。

### 3.6 深度精度问题（Z-Fighting）

由于 `z_n` 与 `z_e` 非线性：

- **近裁剪面附近**精度高
- **远裁剪面附近**精度低

| 建议 | 原因 |
|------|------|
| 尽量缩小 `f - n` | 减少深度缓冲精度浪费 |
| 避免 far 过大 | 远处 z 变化几乎不影响 `z_n` |
| 对数深度等高级方案 | 大场景才需要 |

Song Ho 文中有 near/far 距离与深度精度对比图，见原文 [Comparison of depth precision](https://www.songho.ca/opengl/gl_projectionmatrix.html)。

## 4. 由 FOV 构造 l, r, b, t

实际开发中常用 4 参数：`(fovy, aspect, near, far)`，而非直接给 l,r,b,t。

**垂直 FOV**（对称视锥）：

```
        top
         |\
         | θ/2
         | \
    -----+----- near plane
         O 相机
```

```
t = n * tan(θ/2)
r = t * aspect
```

Song Ho 给出的 `makeFrustum(fovY, aspect, front, back)` 即此转换 + 对称透视矩阵：

```cpp
// 摘自 Song Ho 文章（C++ 伪代码）
float tangent = tan(fovY/2 * DEG2RAD);
float top = front * tangent;
float right = top * aspectRatio;

matrix[0]  =  front / right;
matrix[5]  =  front / top;
matrix[10] = -(back + front) / (back - front);
matrix[11] = -1;
matrix[14] = -(2 * back * front) / (back - front);
matrix[15] =  0;
```

GLM 对应：

```cpp
glm::perspective(glm::radians(fovY), aspect, near, far);
```

内部即完成上述 l,r,b,t 计算并组装矩阵。

### 4.1 水平 FOV

若给定水平 FOV `θ_x`，则：

```
r = n * tan(θ_x / 2)
t = r / aspect
```

见 [Song Ho - Perspective Matrix with Field Of View](https://www.songho.ca/opengl/gl_projectionmatrix.html)。

## 5. 正交投影（Orthographic Projection）

正交投影**无透视**：观察空间到 NDC 是**纯线性缩放+平移**，`w_c = 1`，不做透视除法意义上的深度缩放。

映射关系（[Song Ho Orthographic](https://www.songho.ca/opengl/gl_projectionmatrix.html)）：

```
x_n = 2/(r-l) * x_e - (r+l)/(r-l)
y_n = 2/(t-b) * y_e - (t+b)/(t-b)
z_n = -2/(f-n) * z_e - (f+n)/(f-n)
```

对称正交矩阵（`l=-r, b=-t`）：

```
O_sym =
[  1/r,     0,         0,              0  ]
[    0,   1/t,         0,              0  ]
[    0,     0,   -2/(f-n),            0  ]
[    0,     0,  -(f+n)/(f-n),          1  ]
```

（具体布局与 GLM `glm::ortho` 的 column-major 存储一致；写代码时用 GLM，手推时对照 Song Ho 矩阵。）

### 透视 vs 正交

| | 透视 Perspective | 正交 Orthographic |
|---|------------------|-------------------|
| 数学本质 | 除以 `-z_e`（非线性） | 线性缩放 |
| 视觉效果 | 近大远小 | 远近等大 |
| w 分量 | `w_c = -z_e` | 通常 `w_c = 1` |
| 典型用途 | 3D 游戏场景 | UI、2D、工程图 |
| GLM | `glm::perspective` | `glm::ortho` |

## 6. 完整透视投影矩阵（一般 frustum）

Song Ho 给出的一般 frustum 透视矩阵（非对称亦可）：

```
P =
[  2n/(r-l),        0,       (r+l)/(r-l),           0  ]
[         0,   2n/(t-b),       (t+b)/(t-b),           0  ]
[         0,          0,      -(f+n)/(f-n),    -2fn/(f-n) ]
[         0,          0,                -1,            0  ]
```

**验证思路**（建议手算一次）：

1. 取近裁剪面中心 `(0, 0, -n, 1)`，应得 `z_n = -1`
2. 取远裁剪面中心 `(0, 0, -f, 1)`，应得 `z_n = 1`
3. 取 `x_e = l * (-z_e) / n`，应映射到 `x_n = -1`

## 7. 无穷远裁剪面（扩展）

当 `f → ∞` 时，第三行可简化为（[Song Ho - Infinite Perspective Matrix](https://www.songho.ca/opengl/gl_projectionmatrix.html)）：

对称情况下：

```
P_inf =
[  n/r,     0,     0,     0  ]
[    0,   n/t,     0,     0  ]
[    0,     0,    -1,    -1  ]
[    0,     0,    -n,     0  ]
```

仍无法完全消除深度精度问题，但适合天空盒等「无远面」场景。

## 8. 与 GLM / 代码的对应

**不要手算矩阵元素写进项目**，用 GLM：

```cpp
// 透视
glm::mat4 P = glm::perspective(
    glm::radians(45.0f),           // fovy
    (float)width / (float)height,  // aspect
    0.1f,                          // near
    100.0f                         // far
);

// 正交
glm::mat4 O = glm::ortho(-1.0f, 1.0f, -1.0f, 1.0f, 0.1f, 100.0f);
```

理解推导的目的：

1. 知道 **near/far/fov 改什么**
2. 理解 **深度精度、Z-fighting**
3. 调试时知道 `gl_Position.w` 为何影响最终大小
