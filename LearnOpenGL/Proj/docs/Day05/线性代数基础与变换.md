# 线性代数基础与变换（Day 05 预习）

这份文档对应 Day 05 的**数学预习**。Day 01~04 你已经在 NDC 坐标里直接画三角形、贴纹理；从 Day 06 开始，LearnOpenGL 会引入 **GLM + 变换矩阵**，让物体可以移动、旋转、缩放，并正确处理透视。

本文档不讲 OpenGL API，只讲后面写 Shader 和 C++ 时**必须理解的线代概念**。

---

## 1. 为什么 OpenGL 需要线性代数？

Day 04 的顶点坐标是直接写死在 NDC 里的：

```cpp
0.5f, -0.5f, 0.0f   // 右下，范围 [-1, 1]
```

这种方式有两个问题：

1. **无法方便地移动/旋转物体**——改坐标要手动算每个顶点
2. **无法做 3D 透视**——远近大小一样，不像真实世界

解决方案：用 **矩阵** 对 **向量**（顶点位置）做变换：

```
局部坐标 → 模型矩阵 → 世界坐标 → 视图矩阵 → 观察坐标 → 投影矩阵 → 裁剪坐标
```

Day 05 先把「向量」和「矩阵」本身搞懂；Day 06 再接入 GLM 和 MVP。

---

## 2. 标量（Scalar）

**标量**就是一个数，没有方向。

```
3
-1.5
0.0
```

在 OpenGL / GLSL 里：

| 类型 | 含义 |
|------|------|
| `float` | 单个浮点数 |
| `int` | 整数 |
| `bool` | 真/假 |

标量运算就是普通算术：`+ - * /`。

**在图形学里的用途**：缩放因子、时间、透明度、混合比例等。

---

## 3. 向量（Vector）

**向量**是一组数，在 2D/3D 图形学里通常表示：

- **位置**（一个点相对原点的偏移）
- **方向**（如光线方向、法线方向）
- **颜色**（RGB 可以看成 3 维向量）

### 3.1 常见维度

| 向量 | 写法 | 含义 |
|------|------|------|
| 2D | `(x, y)` 或 `vec2` | 屏幕/纹理平面 |
| 3D | `(x, y, z)` 或 `vec3` | 三维空间位置/方向 |
| 4D | `(x, y, z, w)` 或 `vec4` | 齐次坐标（后面讲） |

### 3.2 几何意义

```
        y
        ↑
        |    • P(2, 3)  ← 从原点 O 指向 P 的箭头
        |   /
        |  /
        O ──────→ x
```

向量 `(2, 3)` 可以表示：

- 点 P 的位置
- 从原点走到 P 的「位移」

### 3.3 GLSL 里的向量

```glsl
vec2 uv = vec2(0.5, 0.5);
vec3 color = vec3(1.0, 0.0, 0.0);
vec4 pos = vec4(1.0, 0.0, 0.0, 1.0);
```

访问分量：`pos.x`、`pos.rgb`、`pos.xy` 等。

## 4. 向量运算

### 4.1 向量 + 向量（逐分量相加）

```
(a, b, c) + (d, e, f) = (a+d, b+e, c+f)
```

**几何意义**：先走第一个向量，再走第二个，等于合成位移。

**用途**：把物体整体平移、把多个力/速度合成。

### 4.2 向量 - 向量

```
(b - a)  表示从点 a 指向点 b 的方向向量
```

**用途**：计算方向、求法线前的边向量。

### 4.3 标量 × 向量（缩放）

```
k * (x, y, z) = (k*x, k*y, k*z)
```

**几何意义**：方向不变，长度变为原来的 `|k|` 倍；`k < 0` 时反向。

**用途**：缩放、调节颜色亮度、匀速运动 `position += speed * deltaTime`。

### 4.4 向量长度（模）

```
|v| = sqrt(x² + y² + z²)
```

GLSL：`length(v)`

### 4.5 单位向量 / 归一化（Normalize）

```
normalize(v) = v / |v|
```

GLSL：`normalize(v)`

**用途**：只要方向不要长度时（光照法线、相机前向）。

**注意**：零向量不能归一化。

### 4.6 点积（Dot Product）

```
a · b = ax*bx + ay*by + az*bz        （结果是标量）
```

GLSL：`dot(a, b)`

**几何意义**：

```
a · b = |a| * |b| * cos(θ)
```

其中 θ 是两向量夹角。

**用途**：

- 判断两向量是否垂直（点积 = 0）
- 光照：`max(dot(normal, lightDir), 0.0)` 计算漫反射强度
- 投影：把一个向量投到另一个方向上

### 4.7 叉积（Cross Product，仅 3D）

```
a × b = 垂直于 a 和 b 的新向量（方向由右手定则决定）
```

GLSL：`cross(a, b)`

**用途**：

- 已知三角形两条边，求 **法线**：`normalize(cross(edge1, edge2))`
- 判断左右、构建坐标系

### 4.8 向量运算速查

| 运算 | 写法 | 结果类型 | 常见用途 |
|------|------|----------|----------|
| 加法 | `a + b` | 向量 | 平移、合成 |
| 减法 | `a - b` | 向量 | 方向、相对位置 |
| 数乘 | `k * a` | 向量 | 缩放 |
| 点积 | `dot(a, b)` | 标量 | 夹角、光照 |
| 叉积 | `cross(a, b)` | 向量(3D) | 法线 |
| 长度 | `length(a)` | 标量 | 距离 |
| 归一化 | `normalize(a)` | 单位向量 | 方向 |

## 5. 矩阵（Matrix）

矩阵是 **数字排成的矩形表格**。在图形学里，矩阵主要用来 **一次性变换很多顶点**。

### 5.1 矩阵维度

| 记号 | 含义 |
|------|------|
| 2×2 | 2D 旋转/缩放 |
| 3×3 | 3D 旋转/缩放（不含平移） |
| 4×4 | **OpenGL 最常用**，可表示平移+旋转+缩放+投影 |

GLM / GLSL 里默认用 **`mat4`（4×4）**。

### 5.2 矩阵 × 向量

把向量当作 **列向量**，矩阵在左边：

```
result = M * v
```

**一次矩阵乘法 = 对向量做一种变换**（旋转、缩放、平移等）。

### 5.3 矩阵 × 矩阵

```
C = A * B
```

**几何意义**：先应用 B 的变换，再应用 A 的变换（顺序很重要）。

LearnOpenGL 常见组合：

```
gl_Position = projection * view * model * vec4(aPos, 1.0);
```

### 5.4 矩阵运算注意事项

| 规则 | 说明 |
|------|------|
| **不满足交换律** | `A * B ≠ B * A`（顺序错了变换结果就错） |
| **结合律成立** | `(A * B) * C = A * (B * C)` |
| **列向量约定** | OpenGL 用列向量，`M * v` |

## 6. 齐次坐标（Homogeneous Coordinates）

3D 位置 `(x, y, z)` 写成 4D `(x, y, z, w)`，其中通常 **`w = 1.0`**。

**为什么多这一维？**

> **用 4×4 矩阵在一个式子里同时表示旋转、缩放和平移。**

3×3 矩阵只能做旋转和缩放，**不能做平移**；4×4 齐次矩阵可以。

透视投影后，GPU 会自动做 **透视除法**：

```
NDC.x = clip.x / clip.w
NDC.y = clip.y / clip.w
NDC.z = clip.z / clip.w
```

这也是 `gl_Position` 必须是 `vec4` 的原因。

## 7. 三种基本变换

### 7.1 平移（Translation）

把物体移动 `(tx, ty, tz)`。

GLM：

```cpp
glm::mat4 T = glm::translate(glm::mat4(1.0f), glm::vec3(0.5f, -0.5f, 0.0f));
```

### 7.2 旋转（Rotation）

绕某个轴旋转角度 θ（右手定则）。

GLM：

```cpp
glm::mat4 R = glm::rotate(glm::mat4(1.0f), glm::radians(45.0f), glm::vec3(0.0f, 0.0f, 1.0f));
```

| 轴 | 效果 |
|----|------|
| X 轴 | 前后翻转（pitch） |
| Y 轴 | 左右转（yaw） |
| Z 轴 | 平面内转（2D 旋转） |

### 7.3 缩放（Scaling）

各轴分别拉伸 `(sx, sy, sz)`。

GLM：

```cpp
glm::mat4 S = glm::scale(glm::mat4(1.0f), glm::vec3(2.0f, 2.0f, 2.0f));
```

### 7.4 组合变换的顺序

```cpp
glm::mat4 model = glm::mat4(1.0f);
model = glm::translate(model, glm::vec3(1.0f, 0.0f, 0.0f));
model = glm::rotate(model, angle, glm::vec3(0, 0, 1));
model = glm::scale(model, glm::vec3(0.5f));
```

矩阵乘法从右往左读：**先 scale，再 rotate，再 translate**（对顶点的作用顺序）。

顺序不同，结果不同——这是初学者最容易踩的坑之一。

## 8. 几种重要的矩阵（特殊矩阵）

### 8.1 单位矩阵（Identity Matrix）

对角线全是 1，其余是 0。乘以任何向量 **不变**。

GLM：`glm::mat4(1.0f)` — 所有变换的起点。

### 8.2 模型矩阵（Model Matrix）

把物体从 **局部空间** 变到 **世界空间**。

### 8.3 视图矩阵（View Matrix）

把 **世界空间** 变到 **相机空间**（以相机为原点）。

GLM：

```cpp
glm::mat4 view = glm::lookAt(
    glm::vec3(0.0f, 0.0f, 3.0f),   // 相机位置
    glm::vec3(0.0f, 0.0f, 0.0f),   // 看向的目标
    glm::vec3(0.0f, 1.0f, 0.0f)    // 上方向
);
```

### 8.4 投影矩阵（Projection Matrix）

**正交投影（Orthographic）**：无透视，物体远近一样大（UI、2D 常用）

```cpp
glm::ortho(left, right, bottom, top, near, far);
```

**透视投影（Perspective）**：近大远小（3D 场景常用）

```cpp
glm::perspective(glm::radians(fov), aspect, near, far);
```

| | 正交 | 透视 |
|---|------|------|
| 远近大小 | 相同 | 近大远小 |
| 典型用途 | 2D、小地图 | 3D 游戏场景 |

### 8.5 MVP 矩阵

```
MVP = Projection × View × Model
```

顶点着色器里：

```glsl
uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

void main()
{
    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

**数据流**：

```
局部坐标 (aPos)
    → model      → 世界坐标
    → view       → 相机坐标
    → projection → 裁剪坐标 (gl_Position)
    → GPU 透视除法 → NDC → 屏幕
```

## 9. 其他会用到的概念（简要）

| 概念 | 说明 | GLM |
|------|------|-----|
| 逆矩阵 | `M * M⁻¹ = I`，视图矩阵常是相机变换的逆 | `glm::inverse(M)` |
| 转置矩阵 | 行变列，法线变换有时用逆转置 | `glm::transpose(M)` |

| Day | 坐标方式 | 局限 |
|-----|----------|------|
| Day 02~03 | 手写 NDC 坐标 | 不能方便移动/旋转 |
