## 2. 基础概念：我们在模拟什么？

真实光照极复杂。实时渲染常用简化模型——**Phong 光照模型**，把光照拆成三项：

```
最终颜色 = Ambient + Diffuse + Specular
```

```
         Specular（高光，朝相机方向的尖峰）
            ↑
           /|
          / |
         /  |  Diffuse（漫反射，表面整体受光）
        /   |
       ●────┴── Ambient（环境光，整体底亮）
      物体
```

| 分量 | 英文 | 直觉 | 依赖什么 |
|------|------|------|----------|
| 环境光 | Ambient | 场景里“到处都有一点光”，避免全黑 | 光色、物体色、环境强度 |
| 漫反射 | Diffuse | 表面朝向光源的一面更亮 | **法线**、光方向 |
| 镜面反射 | Specular | 光滑表面的高光斑 | 法线、光方向、**视线方向** |

## 3. 法线（Normal）：基础光照的关键

### 3.1 法线是什么？

**法线**是垂直于表面的方向向量，表示「这个面朝哪」。

```
        ↑ n（法线）
        |
   ─────┴─────  表面
```

光照里几乎所有「亮不亮」的计算，都要拿法线和光线方向做点积。

### 3.2 为什么立方体每个顶点要带法线？

立方体六个面朝向不同：

| 面 | 典型法线（局部空间） |
|----|----------------------|
| 前面 (+Z) | `(0, 0, 1)` |
| 后面 (-Z) | `(0, 0, -1)` |
| 上面 (+Y) | `(0, 1, 0)` |
| 下面 (-Y) | `(0, -1, 0)` |
| 右面 (+X) | `(1, 0, 0)` |
| 左面 (-X) | `(-1, 0, 0)` |

同一角点在不同面上**法线不同**，所以立方体顶点通常按面展开成 36 个顶点（每个顶点：位置 + 法线），而不是 8 个角点共用。

顶点布局示例（每个顶点 6 个 float）：

```
位置 x,y,z | 法线 nx,ny,nz
```

### 3.3 法线要不要做 MVP？

- **位置**：`projection * view * model * vec4(aPos, 1.0)`
- **法线**：一般只变换到**世界空间**（或观察空间），**不要**用完整 MVP，也不要用带平移的 model 直接乘

原因：

1. 法线是方向，平移无意义；
2. 若 model 有**非等比缩放**，直接用 `mat3(model)` 可能不正确，应使用 **法线矩阵**：

```
normalMatrix = transpose(inverse(mat3(model)))
normal = normalize(normalMatrix * aNormal)
```

等比缩放（或单位 model）时，`normalize(mat3(model) * aNormal)` 往往够用。

### 3.4 单位化

参与点积前，法线和方向向量都应 `normalize`，否则长度会影响亮度。

## 4. 三个分量：为什么要这样算？（形象讲解 + 公式）

把最终颜色想成三层叠在一起：

```
Ambient   = 房间总有一点亮（底光）
Diffuse   = 哪面晒到太阳（大块明暗）
Specular  = 亮晶晶那一小块（高光斑）
```

下面用代码风格写公式（`·` 表示点积；`*` 表示分量相乘或标量乘）。

---

### 4.1 Ambient（环境光）——「房间里总有一点光」

现实里还有天空、地面反弹光，背光处也不会纯黑。实时渲染简化成一个常数：

```
ambientStrength = 0.1                    // 环境光强度 ka，可调
ambient         = ambientStrength * lightColor
ambientResult   = ambient * objectColor  // 再乘物体反射色
```

**完整式：**

```
I_ambient = ka * lightColor * objectColor
```

| 符号 | 含义 |
|------|------|
| `ka` | 环境光系数（0~1） |
| `lightColor` | 灯光 RGB |
| `objectColor` | 物体对各通道的反射比例 |

不需要法线、不需要相机位置——只保证「别整块剪影」。

---

### 4.2 Diffuse（漫反射）——「脸朝太阳有多正」

#### 生活直觉

想象**粗糙的墙**（粉笔墙、哑光塑料）：

- 光打上去往四面八方散射；
- 你站在哪看，大致都「亮一点」；
- 但**正对灯的那一面最晒**。

漫反射**不关心你站哪**，只问：

> 这面墙有多正对着灯？

#### 两个箭头

```
        ↑ N（法线：墙朝哪 / 你的脸朝哪）
        |
   ─────┴─────  表面
       ↗
      L（光方向：从表面指向灯）
```

| 符号 | 代码 | 含义 |
|------|------|------|
| `N` | `normalize(Normal)` | 表面朝外 |
| `L` | `normalize(lightPos - FragPos)` | 片元 → 光源 |

`normalize`：只问方向，不问「多远」（像只看指南针）。

#### 为什么用点积？

单位向量的点积 = 夹角余弦：

```
N · L = cos(θ)
```

| 夹角 θ | cos(θ) | 观感 |
|--------|--------|------|
| 0°（正对灯） | 1 | 最晒、最亮 |
| 60° | 0.5 | 半亮 |
| 90°（擦边） | 0 | 几乎没晒到 |
| >90°（背光） | <0 | 灯在背后 |

背光时余弦为负，但光不会「吸走颜色」，所以要夹断：

```
diff = max(N · L, 0)
```

#### 完整漫反射公式

```
N      = normalize(Normal)
L      = normalize(lightPos - FragPos)
diff   = max(dot(N, L), 0.0)              // 兰伯特系数 ∈ [0, 1]
diffuse = diff * lightColor
I_diffuse = diffuse * objectColor
```

或写成一条：

```
I_diffuse = max(N · L, 0) * lightColor * objectColor
```

这就是 **Lambert（兰伯特）漫反射定律**：亮度 ∝ 入射角余弦。

#### 为什么要这样做？

1. **便宜**：每像素一个点积，GPU 轻松；
2. **直觉对**：脸朝太阳亮、背太阳暗；
3. **够用**：墙、布料、哑光塑料大部分靠它。

当前项目 `lightTest.fs` 已实现 Ambient + Diffuse（灯绕物体转，便于观察明暗）。

---

### 4.3 Specular（镜面高光）——「你有没有站在反光路上」

#### 生活直觉

漫反射像粉笔墙：整面渐变亮。  
高光像：

- 湿地板上的太阳斑；
- 台球 / 苹果上的小白点；
- 车漆反光。

特点：

1. **只在特定角度很亮**；
2. **跟着视角走**——你一歪头，光斑会挪。

所以必须知道**相机在哪**（视线 `V`）。

#### Phong 反射故事

光打到表面会「弹」出去，像台球撞边：

```
入射  ↘
       ●────→ N
      ↗
 反射 R
```

眼睛要在反射方向附近，才能看到刺眼的亮：

```
         V（片元 → 相机）
          ↗
         ●──── R（反射方向）
        /
       ↙ -L（入射，指向表面）
```

`V` 与 `R` 越近 → 高光越强。

#### 完整 Phong 镜面公式

```
V = normalize(viewPos - FragPos)     // 视线：片元 → 相机
R = reflect(-L, N)                   // 反射方向
// 注意：GLSL reflect(I, N) 要求 I 是「指向表面」的入射，
// 而 L 是「指向灯」的，所以用 -L

ks         = 0.5                     // specularStrength
shininess  = 32                      // 越大高光越尖、越小

spec       = pow(max(V · R, 0), shininess)
specular   = ks * spec * lightColor
I_specular = specular * objectColor  // 也可只乘高光色，视材质而定
```

一条式：

```
I_specular = ks * (max(V · R, 0) ^ shininess) * lightColor * objectColor
```

| 参数 | 作用 | 调参感觉 |
|------|------|----------|
| `ks` / `specularStrength` | 高光总强弱 | 太大抢戏，太小看不见 |
| `shininess` | 高光尖锐度 | 小（如 2~8）糊成一片；大（64~256）又小又尖（更「镜」） |

#### Blinn-Phong（可选，更常见）

不显式算反射向量，改用**半程向量**：

```
H = normalize(L + V)                 // 光方向与视线的「中间方向」
spec = pow(max(N · H, 0), shininess)
I_specular = ks * spec * lightColor * objectColor
```

半程向量更稳、计算更省，现代教程常用。

---

### 4.4 合成：Phong 总公式

```
I = I_ambient + I_diffuse + I_specular

  = ka * lightColor * objectColor
  + max(N·L, 0) * lightColor * objectColor
  + ks * (max(V·R, 0)^shininess) * lightColor * objectColor

FragColor = vec4(I, 1.0)
```

也可先合成光的贡献再乘物体色（与上面等价，若三项都乘同一 `objectColor`）：

```
I = (ka * lightColor
   + max(N·L, 0) * lightColor
   + ks * (max(V·R, 0)^shininess) * lightColor)
  * objectColor
```

#### 三项对比（速查）

| | Ambient | Diffuse | Specular |
|---|---------|---------|----------|
| 像什么 | 房间底光 | 晒太阳 / 粉笔墙 | 镜面光斑 |
| 关不关心你站哪 | 否 | **否** | **是**（要 `viewPos`） |
| 核心计算 | `ka * light` | `max(N·L, 0)` | `pow(max(V·R, 0), shininess)` |
| 画面效果 | 整体抬亮 | 大块明暗 | 局部尖亮点 |

---

### 4.5 公式速查表（抄代码用）

```
符号约定（世界空间，均为单位向量）：
  N = normalize(Normal)
  L = normalize(lightPos - FragPos)     // 到灯
  V = normalize(viewPos - FragPos)      // 到相机
  R = reflect(-L, N)                    // Phong 反射
  H = normalize(L + V)                  // Blinn 半程

环境光:
  I_a = ka * lightColor * objectColor

漫反射 (Lambert):
  I_d = max(N · L, 0) * lightColor * objectColor

镜面 (Phong):
  I_s = ks * pow(max(V · R, 0), shininess) * lightColor * objectColor

镜面 (Blinn-Phong):
  I_s = ks * pow(max(N · H, 0), shininess) * lightColor * objectColor

最终:
  FragColor.rgb = I_a + I_d + I_s
  FragColor.a   = 1.0
```

典型参数起点：`ka=0.1`，`ks=0.5`，`shininess=32`。

---

## 4.6 向量方向别搞反（易错）

| 写法 | 对不对 | 说明 |
|------|--------|------|
| `L = lightPos - FragPos` | ✅ | 从表面指向灯 |
| `L = FragPos - lightPos` | ❌ | 方向反了，明暗会反 |
| `V = viewPos - FragPos` | ✅ | 从表面指向相机 |
| `reflect(-L, N)` | ✅ | GLSL 入射约定 |
| `reflect(L, N)` | ❌ | 反射方向错，高光乱飞 |
| `max(dot(...), 0)` | ✅ | 背光截断 |
| 忘记 `normalize` | ❌ | 距离会影响亮度（不该） |

## 5. 需要哪些「世界空间」量？

片元着色器通常在**同一坐标系**里算光照（常用世界空间）：

| 量 | 含义 | 常见来源 |
|----|------|----------|
| `FragPos` | 片元世界坐标 | VS：`vec3(model * vec4(aPos,1))` 再传给 FS |
| `Normal` | 法线（世界空间） | VS：法线矩阵变换后传给 FS |
| `lightPos` | 光源世界坐标 | C++ uniform |
| `viewPos` | 相机世界坐标 | C++：`camera.Position` |
| `lightColor` / `objectColor` | 光色、物色 | C++ uniform |

伪代码流程：

```
顶点着色器:
  FragPos = model * aPos          // 世界位置
  Normal  = normalMatrix * aNormal
  gl_Position = P * V * model * aPos

片元着色器:
  算 ambient
  算 diffuse（用 Normal, lightPos, FragPos）
  算 specular（再加 viewPos）
  FragColor = ambient + diffuse + specular
```

## 6. 代码骨架展示

### 6.1 顶点数据：位置 + 法线

```cpp
// 每个顶点：3 位置 + 3 法线
float vertices[] = {
    // positions          // normals
    -0.5f, -0.5f, -0.5f,  0.0f,  0.0f, -1.0f,
     0.5f, -0.5f, -0.5f,  0.0f,  0.0f, -1.0f,
     // ... 其余面同理，共 36 个顶点
};

glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)(3 * sizeof(float)));
glEnableVertexAttribArray(1);
```

灯立方体若仍只画白色小方块，可以继续**只绑位置属性**，共用 VBO 时注意 stride（或单独 VBO）。

### 6.2 顶点着色器（物体）

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNormal;

out vec3 FragPos;
out vec3 Normal;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

void main()
{
    FragPos = vec3(model * vec4(aPos, 1.0));
    // 简单写法（适合无非等比缩放）：
    Normal = mat3(transpose(inverse(model))) * aNormal;

    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

### 6.3 片元着色器（物体，Phong）

```glsl
#version 330 core
out vec4 FragColor;

in vec3 FragPos;
in vec3 Normal;

uniform vec3 objectColor;
uniform vec3 lightColor;
uniform vec3 lightPos;
uniform vec3 viewPos;

void main()
{
    // Ambient
    float ambientStrength = 0.1;
    vec3 ambient = ambientStrength * lightColor;

    // Diffuse
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(lightPos - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = diff * lightColor;

    // Specular
    float specularStrength = 0.5;
    vec3 viewDir = normalize(viewPos - FragPos);
    vec3 reflectDir = reflect(-lightDir, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), 32.0);
    vec3 specular = specularStrength * spec * lightColor;

    vec3 result = (ambient + diffuse + specular) * objectColor;
    FragColor = vec4(result, 1.0);
}
```

### 6.4 C++ 侧每帧传参要点

```cpp
lightingShader.use();
lightingShader.setVec3("objectColor", objectColor.x, objectColor.y, objectColor.z);
lightingShader.setVec3("lightColor", lightColor.x, lightColor.y, lightColor.z);
lightingShader.setVec3("lightPos", lightPos.x, lightPos.y, lightPos.z);
lightingShader.setVec3("viewPos", camera.Position.x, camera.Position.y, camera.Position.z);
// 再传 model / view / projection，然后 Draw 物体

lampShader.use();
// 灯可继续用恒定色或同一个 lightColor 可视化灯位
```

与 Day01 相比，多传的关键是：

- `lightPos`：算光方向
- `viewPos`：算视线方向（镜面反射）
- 顶点里的 **法线 attribute**

## 7. 完整数据与执行流程

```
初始化:
  准备带法线的 vertices
  上传 VBO；配置 cubeVAO（location0=位置, location1=法线）
  灯 VAO 可仍只读位置
  编译 lightingShader / lampShader

每帧:
  1. 输入 → 更新 Camera
  2. 清屏（颜色 + 深度）
  3. 算 view / projection

  4. 画物体:
     lightingShader.use()
     传 objectColor, lightColor, lightPos, viewPos, MVP
     bind cubeVAO → DrawArrays(36)
        → VS 输出 FragPos, Normal
        → FS 算 Ambient+Diffuse+Specular → 上色

  5. 画灯:
     lampShader.use()
     model = translate(lightPos) * scale(0.2)
     bind lightVAO → DrawArrays(36)
        → 灯只显示颜色，不做光照计算

  6. SwapBuffers / PollEvents
```

片元级伪代码：

```
对每个片元:
  N = normalize(法线)
  L = normalize(灯位置 - 片元位置)      // 光方向
  V = normalize(相机位置 - 片元位置)    // 视线

  ambient  = ka * lightColor
  diffuse  = max(N·L, 0) * lightColor
  R        = reflect(-L, N)
  specular = ks * (max(V·R, 0) ^ shininess) * lightColor

  color = (ambient + diffuse + specular) * objectColor
```

## 8. 常见问题

| 现象 | 可能原因 |
|------|----------|
| 整块仍同色、无法线感 | 顶点没传法线 / attribute 没 enable / shader 没用 Normal |
| 光照方向反了 | `lightDir` 写成了 `FragPos - lightPos` |
| 高光没有 | 没传 `viewPos`，或 shininess / strength 过小 |
| 缩放后光照扭曲 | 法线没用 `transpose(inverse(model))` |
| 某面全黑 | 法线方向反了（指向面内） |
| 灯颜色对、物体不对 | 物体 shader 仍是 Day01 的单纯相乘 |

## 9. 与当前项目的关系

当前工程已实现完整 **Phong：Ambient + Diffuse + Specular**（灯绕物体旋转）：

| 文件 | 状态 |
|------|------|
| `shaders/lightTest.vs` | 输出 `FragPos`、`Normal`（法线矩阵变换） |
| `shaders/lightTest.fs` | `I = (ambient + diffuse + specular) * objectColor` |
| `main.cpp` | 顶点含法线；传入 `lightPos`、`viewPos`（`camera.Position`） |

片元核心：

```glsl
vec3 N = normalize(Normal);
vec3 L = normalize(lightPos - FragPos);
vec3 V = normalize(viewPos - FragPos);
vec3 R = reflect(-L, N);

vec3 ambient  = 0.1 * lightColor;
vec3 diffuse  = max(dot(N, L), 0.0) * lightColor;
vec3 specular = 0.5 * pow(max(dot(V, R), 0.0), 32.0) * lightColor;
vec3 result   = (ambient + diffuse + specular) * objectColor;
```

可调参：`ambientStrength`、`specularStrength`、`shininess`（当前 32）。  
灯的 `lamp` shader 仍只负责标出灯位与 `lightColor`。

## 10. 小练习

1. 只开 Ambient，关掉 Diffuse/Specular，画面应接近均匀暗色。
2. 只开 Diffuse：绕立方体转一圈，应看到朝向 `lightPos` 的面更亮。
3. 提高 `shininess`（如 2 → 256），高光应变小、更尖。
4. 把灯绕物体转（改 `lightPos`），观察明暗与高光是否跟着动。
5. 物体绕 Y 轴旋转时，若法线变换正确，受光面应随之变化。
