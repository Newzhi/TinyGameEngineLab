## 1. 本节目标

1. 理解图形学里「看见的颜色」= **光源色 × 物体反射色**（分量相乘）。
2. 搭一个干净的实验场：一个**被照物体**（箱子）+ 一个**表示灯位置的白色立方体**。
3. 为后续真正做光照计算留好结构（灯与物体着色器分离）。

运行后应看到：深色背景里一个**珊瑚红色**大立方体，以及右上方一个**白色**小立方体（灯）。WASD + 鼠标可绕场景观察。

## 2. 颜色：RGB 与「反射」直觉

### 2.1 数字如何表示颜色

现实颜色无限，计算机用有限数值近似。常用 **RGB** 三分量组合出颜色，例如珊瑚红：

```cpp
glm::vec3 coral(1.0f, 0.5f, 0.31f);
```

### 2.2 我们看到的并不是「物体固有色」本身

肉眼看到的颜色，是物体**反射**到眼睛里的光：

- 白光 ≈ 多种可见光的混合；
- 物体**吸收**一部分波长，**反射**其余部分；
- 反射部分的组合 = 感知到的颜色。

例：白光打在蓝玩具上 → 大多波长被吸收，蓝光反射 → 看起来是蓝色。

> 更精确的物理模型会在 PBR 章节再展开；本节用简化的「分量相乘」就够用。

### 2.3 图形学里的公式

```
最终颜色 = lightColor * objectColor   // 按 R/G/B 分量分别相乘
```

| 光源 | 物体（珊瑚红） | 结果 | 观感 |
|------|----------------|------|------|
| 白 `(1,1,1)` | `(1, 0.5, 0.31)` | `(1, 0.5, 0.31)` | 珊瑚红 |
| 绿 `(0,1,0)` | `(1, 0.5, 0.31)` | `(0, 0.5, 0)` | 深绿 |
| 深橄榄 `(0.33, 0.42, 0.18)` | `(1, 0.5, 0.31)` | `(0.33, 0.21, 0.06)` | 偏暗的黄绿 |

**要点**：物体色可理解为「对各颜色分量的反射比例」；换光源色，同一物体会看起来完全不同。

可在 `main.cpp` 里改 `lightColor` 立刻验证上表。

## 3. 实验场景结构

| 角色 | 用什么画 | Shader | 作用 |
|------|----------|--------|------|
| 被投光物体 | 立方体（原点） | `lightTest` | 验证颜色相乘；后续接真正光照 |
| 光源可视化 | 小立方体（`lightPos`） | `lamp` | 只标记灯的世界坐标，恒白 |

顶点仅上传 **位置**（`vec3`），本节不用纹理坐标。

## 4. 物体着色器

### 4.1 顶点着色器（`lightTest.vs`）

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

void main()
{
    gl_Position = projection * view * model * vec4(aPos, 1.0);
}
```

### 4.2 片段着色器（`lightTest.fs`）

```glsl
#version 330 core
out vec4 FragColor;

uniform vec3 objectColor;
uniform vec3 lightColor;

void main()
{
    FragColor = vec4(lightColor * objectColor, 1.0);
}
```

CPU 侧（先 `use` 再设 uniform）：

```cpp
lightingShader.use();
lightingShader.setVec3("objectColor", 1.0f, 0.5f, 0.31f);
lightingShader.setVec3("lightColor",  1.0f, 1.0f, 1.0f);
```

---

## 5. 为什么灯要单独 VAO / Shader？

后续会不断改物体的顶点布局、光照片段着色器。若灯和箱子共用同一套配置：

- 改属性指针可能误伤灯；
- 灯的颜色会被光照结果「带偏」，不像一盏亮灯。

因此：

1. **灯单独 `lightVAO`**：仍绑定物体那个 VBO（立方体顶点已在里面），只配 `location = 0` 的位置属性。
2. **灯单独片段着色器**：恒定白色输出，不受场景光照影响。

```cpp
glBindVertexArray(lightVAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
```

`lamp.fs`：

```glsl
#version 330 core
out vec4 FragColor;

void main()
{
    FragColor = vec4(1.0);
}
```

顶点着色器与物体相同（MVP × 位置），本项目拆成 `lamp.vs` 便于以后各自演进。

## 6. 光源位置与绘制顺序

```cpp
glm::vec3 lightPos(1.2f, 1.0f, 2.0f);

model = glm::mat4(1.0f);
model = glm::translate(model, lightPos);
model = glm::scale(model, glm::vec3(0.2f));
```

每帧建议顺序：

1. `lightingShader` → 设颜色 / MVP → 画大立方体  
2. `lampShader` → 设 MVP（translate + scale）→ 绑 `lightVAO` → 画小白立方体

## 7. 实现时注意点（本仓库踩过的坑）

| 问题 | 正确做法 |
|------|----------|
| VBO 若仍是「位置+颜色+UV」布局，灯 VAO 却用 `stride = 3 * sizeof(float)` | 要么改成仅位置顶点，要么 stride 与整顶点步长一致 |
| 只 `use` 了光照 Shader 却用纹理 Shader 画物体 | 物体必须用 `lightTest`，灯用 `lamp` |
| 忘了画 `lightVAO` | 场景里看不到灯的位置标记 |
| 改 Shader 后未同步到构建目录 | CMake `file(COPY shaders ...)`；改完需重新配置/复制或手动拷贝 |
